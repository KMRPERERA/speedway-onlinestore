# Speedway-Onlinestore
SpeedWay is an online e-commerce platform for vehicle parts, offering a wide range of products with a smooth shopping experience. Built for speed, reliability, and easy browsing.

##  Features

-  **Smart Search and Filtering**
-  **Cash on Delivery (Current)**
-  **Order Tracking System**
-  **Responsive Web Design**
-  **User and Supplier Accounts**
-  **Admin Dashboard**
-  **Cloudinary Integration for Image Storage**

---

##  Tech Stack

###  Frontend
- **Figma** (Design tool for user interfaces)
- **React.js** (Functional components, Hooks)
- **Visual Studio Code**(Code editor for building interfaces)
- **Cloudinary** (for image upload and display)
- **Vercel** (Platform for frontend hosting and deployment)

###  Backend
- **C#.NET** (Programming launguage for backend API development
- **Microsoft SQL Server** (Database management system)
- **Microsoft Hosting Services** (Cloud platform for backend hosting)
- **Visual Studio** ( Intergrated development environmental for backend development)
